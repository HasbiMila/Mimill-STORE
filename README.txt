HPKU GitHub Pages

Upload index.html, products.js, dan admin.html ke repository.
Aktifkan Settings > Pages > Deploy from branch > main > /(root).
Pelanggan: https://USERNAME.github.io/REPOSITORY/
Admin editor: https://USERNAME.github.io/REPOSITORY/admin.html

Setelah mengubah katalog di admin.html, klik Download products.js, lalu upload/replace products.js di GitHub.
Versi ini statis: admin tidak menulis langsung ke GitHub.
